How to Host this App & Share Online

To share this showcase with clients and colleagues so it runs 24/7 without needing your laptop open, we use GitHub Pages for the site and Google Drive / OneDrive for the video storage.

1

Upload Videos to Cloud Storage

Upload the video files from E:\Demos to Google Drive or OneDrive.

  • Google Drive: Upload files, right-click, select Share, and set permission to "Anyone with the link can view". Copy the link.
  • OneDrive: Upload files, right-click, select Share, ensure it is set to "Anyone with the link can view". Copy the link.
2

Update `videos.json` with Cloud Links

Open the project's public/videos.json file in a text editor. Locate the video items and update their onlineUrl field with the copied share link.

{
  "filename": "AFP demo 1.mp4",
  "title": "AFP Demo 1",
  "category": "Demos",
  ...
  "onlineUrl": "PASTE_YOUR_GOOGLE_DRIVE_OR_ONEDRIVE_LINK_HERE"
}
3

Host on GitHub Pages (Free)

  1. Create a free repository on GitHub (e.g. ingenero-showcase).
  2. Commit and push the contents of the public/ folder to this repository.
  3. In your GitHub Repository, go to Settings > Pages.
  4. Under Build and deployment, select the main branch (root) and click Save.
  5. Within 1-2 minutes, your showcase will be online at https://<your-username>.github.io/ingenero-showcase/!

Note: When you open the hosted website, the application automatically converts Google Drive and OneDrive links into direct playback streams, ensuring a premium streaming experience.
